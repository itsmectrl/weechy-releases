## Verify

The SHA-256 checksum of the APK is provided with the release.

Linux / macOS:

```bash
sha256sum Weechy-2.0-New-version.apk
```

Windows:

```cmd
certutil -hashfile Weechy-2.0-New-version.apk SHA256
```
