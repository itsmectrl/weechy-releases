# Weechy Releases

Official APK releases for **Weechy**, a lightweight local music player for Android.

## Download

The current available release is:

**New Version 1.0**

Download Weechy from the official website:

**https://weechyapp.web.app**

## Install

1. Download the APK.
2. Allow installation from your browser when Android asks.
3. Install Weechy.
4. Allow access to your music.

## Verify

The SHA-256 checksum of the APK is provided with the release.

Linux / macOS:

```bash
sha256sum Weechy-1.0-New-version.apk
```

Windows:

```cmd
certutil -hashfile Weechy-1.0-New-version.apk SHA256
```
